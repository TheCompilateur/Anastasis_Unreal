# Recherche : histoire du Pont grec (1000-1461 et après)

Faits historiques sourcés pour ANÁSTASIS : un village de réfugiés grecs vers 1204, dans une zone
abandonnée du Pont, hors de toute faction, exposée aux Turcs.

Règles d'usage pour un agent :

- Ce dossier est une **réserve de preuves**, pas une spécification de gameplay.
- Un fait historique qui entre dans le jeu va dans les **données de scénario**, avec sa source
  (id de document + page) et son statut (`[V]` vérifié, `[I]` inférence, `[A]` abstraction, `[?]`
  inconnu). Jamais en dur dans le C++.
- Ne pas promouvoir un `[I]` ou un `[?]` en `[V]` sans relire la source.
- Les textes OCR des livres ne sont pas commités (droits) : ils se retéléchargent depuis archive.org
  (liens dans HP-001, §2).
